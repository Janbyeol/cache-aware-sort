# Idea 5 AVX2 정렬 벤치마크

2026-11-19 · Windows x64 · Intel Core Ultra 7 270K Plus · MSVC Release

동일한 입력과 컴파일러로 기존 일곱 정렬과 Idea 5를 측정했다. 아래 배수는 기준 정렬 시간 ÷ Idea 5 시간이다. 1보다 크면 Idea 5가 빨랐다.

**Idea 4 대비 전체 기하평균은 4B 키 1.03×, 8B 레코드 0.53×였다.** 4B에서는 16개 키가 정확히 한 리프를 채우는 크기의 이득이 컸다. N=16을 제외한 77개 조건의 기하평균은 0.98×였다. 8B에서는 100만 원소의 일곱 입력 모두 Idea 5의 시간이 늘었고, 같은 시드끼리 짝지은 49회 비교에서도 모두 그랬다.

## 4B 병합의 꼬리 처리 실험

4B 키 100만 개에서 리프를 Idea 4로 고정하고, 같은 입력으로 네 가지 병합 구성을 각각 12회 실행했다. 각 구성은 실행 순서의 네 위치를 세 번씩 차지했고 측정 후 정렬 결과를 검증했다.

무작위 3D 거리의 중앙값은 Idea 4가 **25.28 ms**, 기존 AVX2 병합이 **30.60 ms**였다. AVX2의 마지막 두 `std::merge`를 동등한 수동 루프로 교체하면 **30.81 ms**, 한쪽 입력이 소진됐을 때 중간 버퍼를 생략하면 **30.52 ms**였다. 두 변경 모두 이 입력에서 관찰된 약 5.3 ms의 차이를 해소하지 못했다.

각 입력의 첫 시드로 별도 정렬을 실행해 벡터 병합의 전체 겹침 길이와 꼬리에서 출력한 원소 수를 합산했다. 무작위 3D 거리에서 꼬리 출력 비율은 6.99%였다. 이 비율의 단위는 원소 수다. [7개 입력 요약](tail_merge_summary.csv) · [반복별 시간](tail_merge_timings.csv) · [꼬리 원소 집계](tail_merge_counts.csv)

## 측정 방법과 검증 범위

- Windows x64 26H2 빌드 26300.9974, 논리 프로세서 24개. 균형 조정 전원 계획과 일반 우선순위로 두 자료형을 순차 실행했다. 측정 프로세스의 affinity는 논리 프로세서 2(마스크 4)로 고정했다.
- 작업 트리는 커밋 `1820a7f2b83bcadaa01587af4f6e5d4a05d02895`에 이 대화에서 구현한 Idea 5 변경을 포함한다. Visual Studio C++ 19.52.37029, x64 Release, 정렬 오브젝트는 기존 테스트·벤치마크 빌드의 것을 재사용했다. 측정 전용 소스는 /O2 /Oi /Ot /GL /MD, 링크는 /LTCG를 사용했다.
- `HSORT_SIMD_ISA=avx2`, `HSORT_SIMD_STAGE=both`. 정확성 테스트는 AVX2와 SSE2에서 각각 4B·8B 모두 3,833개 검사를 통과했다. 성능 수치는 AVX2에서만 측정했다.
- 기본 벤치마크와 Linux 보관 자료의 크기를 합쳐 N = 16, 64, 128, 256, 1024, 2048, 8192, 32768, 131072, 262144, 1000000, 5000000을 측정했다. 각 입력·크기·자료형에서 원본을 매번 새로 생성하고 8개 정렬에 같은 배열을 복사했다. 시드는 `0x900dbeef + 31*N + 997*시나리오번호 + 반복번호(0~6)`를 사용했다.
- 각 조건을 7회 측정했다. 홀수 회차는 등록 순서, 짝수 회차는 역순으로 실행했다. 워밍업은 각 정렬에 동일한 입력을 제공했다. 작은 입력은 기본 코드와 같은 방식으로 여러 배열을 묶어 배열당 시간으로 환산했다.
- 정렬 내부의 할당과 복사를 포함한다. 입력 생성, 정렬 전 복사와 결과 검증은 타이머 밖이다. 주 측정의 9,408개 배치에서 총 1,148,560개 배열의 정렬된 키를 검증했고, 8B는 ID 중복·누락 및 키와 ID의 대응까지 검사했다. 단계별 추가 측정 392개도 같은 검증을 통과했다.
- 주 측정의 실행 파일은 기존 벤치마크 드라이버에 [측정 전용 패치](measurement.patch)를 적용한 임시 사본을 컴파일해 만들었다. 정렬·입력 생성 코드는 동일하다. 단계별 비교는 [전용 드라이버](stages.cpp)를 같은 정렬 오브젝트와 링크했다. 단계별 실행 순서는 반복마다 한 칸씩 회전한다.
